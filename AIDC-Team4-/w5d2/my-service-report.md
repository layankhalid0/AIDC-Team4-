# Service report

Team: Team 4

Use case: OpenAI-compatible chat model serving for the Agentic AI project; the service provides model inference infrastructure for the agent team.

Service and model: vLLM serving endpoint in the team namespace using Qwen/Qwen2.5-1.5B-Instruct-AWQ.

Measured requests or tasks: Artificial chat requests generated by the supplied W5D2 traffic.py client.

Indicator and unit: 95th percentile time to first token (p95 TTFT), seconds.

SLO target and window: p95 TTFT <= 0.10 seconds over the proposed 30-minute SLO window, using a Prometheus [5m] query window.

Measurement start and end: Measurement workload started at 2026-09-14 08:35:58 UTC (11:35:58 Saudi Arabia time). The reported value was observed during the traffic workload.

Workload: W5D2 traffic.py artificial chat workload against Qwen/Qwen2.5-1.5B-Instruct-AWQ with max_tokens=64. The client began with a single-caller phase and uses bounded concurrency of up to four callers.

Observed result and sample count: p95 TTFT = 0.03881 seconds (38.81 ms) during the observed workload. The exact request count at the instant of the Grafana preview was not recorded.

Evidence: Grafana Team service alert preview and Prometheus vLLM TTFT metric. notification-evidence.jsonl contains the separate alert notification test evidence.

Conclusion: insufficient evidence

Limitations: The observation covers only a short artificial workload. TTFT is measured server-side and excludes network and client-side latency. The exact request count at the instant of the reported Grafana measurement was not recorded. The workload does not cover the full proposed 30-minute SLO window, and model-output quality is not measured by this indicator.

Follow-up action: Run a sustained representative workload for at least the full 30-minute SLO window, record the request count and measurement timestamps, and evaluate p95 TTFT under representative concurrency.

## Measurement query

```promql
histogram_quantile(
  0.95,
  sum by (le) (
    rate(vllm:time_to_first_token_seconds_bucket[5m])
  )
)
```

The query was evaluated in Grafana during the W5D2 traffic workload on 2026-09-14. It measures server-side vLLM time to first token over a 5-minute Prometheus rate window. It does not include network latency, client-side latency, or model-output quality.

Relationship to the SLO: The alert detects when the measured p95 TTFT exceeds the proposed SLO target of 0.10 seconds. The alert uses the same p95 TTFT indicator and [5m] Prometheus measurement window documented for the service.

First response to a notification: Check the vLLM serving deployment and recent request load, then inspect the TTFT metric and service health for the affected period.
