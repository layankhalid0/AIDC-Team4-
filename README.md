# W4D1 - Deployment Verification (`remas` Namespace) 

This directory contains the deployment configuration and verification files for **W4D1** executed under the `remas` namespace using port `8000`.

## 📂 Files Included
- `pod.yaml`: The deployment pod configuration targeting port `8000`.
- `verify.sh`: The automated verification script configured to test the endpoint.
- `w4d1_evidence.json`: The evidence output generated from the validation checks.

## 🛠️ Verification Steps
1. Applied the pod configuration in the `remas` namespace.
2. Executed the verification script to check service health and connectivity on port `8000`.
